# Contributing to DataTab

Issues are welcome. Use this repository to report bugs and request features.
Include your DataTab version, operating system, and steps to reproduce a bug.
Remove passwords, tokens, connection strings, and private data from reports.

Pull requests are not accepted.

To build from source, see [Building DataTab](docs/BUILDING.md).
For private security reports, use the contact in [SECURITY.md](SECURITY.md).
